# Проверка версии 0.2.0

Среда проверки: Windows, OBS Studio 33.0.1, RTX 3080. Дата: 11 ноября 2026 года.

## Подтверждено

- Нативная DLL собрана с заголовками OBS 33.0.1 и FFmpeg 8, загружается настоящим libobs / Direct3D 11.
- Производственный Java-класс `Wire` передаёт тестовый H.264 в производственный приёмник Windows через AES-GCM. Поворот 90° подтверждён расположением четырёх цветовых областей после декодирования и вывода OBS.
- Итоговый прогон: 126 корректных видеокадров; уровни яркости квадрантов 41 / 77 / 235 / 149.
- Проверены отдельные пакеты параметров SPS/PPS, отклонение неверного ключа и повторное подключение.
- HTTP endpoint сопряжения отклоняет запрос с неверным Host и не выдаёт ключ клиенту по LAN-адресу.
- Сравнение версий проверено на одинаковых, старых, новых, многозначных и некорректных версиях. Проверены ограничения HTTPS, точного репозитория/имени установщика и формата SHA-256.
- APK собран Android Build Tools 35.0.1, подпись проверена `apksigner verify` по схемам v2 и v3. Для обновления используется тот же локальный ключ подписи, что и для версии 0.1.
- Оконная подсистема EXE-установщика проверена. Его реальный код распаковки извлёк все 8 файлов в новую тестовую папку; SHA-256 каждого файла совпал с пакетом. Системная установка в этом тесте не выполнялась.

## Границы проверки

Тестовый ролик подтверждает протокол и декодирование, но не заменяет испытания Camera2 / MediaCodec на конкретном Android. Реальная камера, сканер QR и поведение на разных моделях телефонов пока не проверены. Длительная трансляция, точная задержка и работа с перегруженным Wi-Fi не измерялись.

Установщик умеет проверять наличие OBS, просить закрыть процесс и сохранять старую папку. Административное повышение и установка на чистой Windows в автоматизированном тесте не выполнялись.

## Дополнительная проверка после публикации

- Все четыре файла релиза скачаны по публичным постоянным ссылкам `/releases/latest/download/...` без аутентификации. Их содержимое совпало с локальными файлами, SHA-256 совпал с данными GitHub API.
- Настоящий код проверки/скачивания проверен с опубликованным релизом и имитированными ответами пользователя. Тестовая сборка сообщала более старую текущую версию; системные диалоги и открытие папки были заменены тестовыми функциями, папка Downloads — отдельной рабочей папкой. Отказ создал 0 установщиков, согласие — 1 установщик, побайтно совпадающий с опубликованным. Исполняемый файл не запускался.
- На текущем компьютере новая DLL и данные установлены вручную из проверенного пакета при закрытом OBS; предыдущие файлы сохранены отдельно. После запуска OBS QR скачивания APK виден в свойствах источника, ручная кнопка обновлений показала сообщение об актуальной версии 0.2.0.
- Оконный мастер установщика не был проверен через Computer Use: инструмент не предоставил доступ к этому новому приложению. Проверка его настоящей распаковки и всех файлов выполнена независимо от интерфейса. Это ограничение не следует считать подтверждением полного прохождения мастера.
