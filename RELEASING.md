# Выпуск обновлений

1. Измените версию в `plugin/src/release.h`, Android manifest и текстах установщика/его manifest. Для APK увеличьте `android:versionCode`. Добавьте описание в `CHANGELOG.md`.
2. Соберите DLL, APK и установщик, используя прежний приватный ключ APK. Не публикуйте рабочую папку, ключ, пароль или локальные настройки сопряжения.
3. Выполните проверки видео, метаданных обновлений, распаковки установщика и подписи APK. Проверьте изменения на реальном смартфоне.
4. Создайте git-тег вида `v0.2.1`, совпадающий с версией сборки, и обычный GitHub Release для этого тега.
5. Прикрепите к одному релизу файлы со стабильными именами:
   - `OBS-LAN-Camera-Setup.exe`
   - `OBS-LAN-Camera-Android.apk`
   - `OBS-LAN-Camera-Windows-x64.zip`
   - `SHA256SUMS.txt`
6. В описание релиза внесите понятные пользователю изменения. Именно это описание появится в окне обновления.

Для доступности `/releases/latest` релиз должен быть опубликованным обычным релизом: черновики и prerelease пропускаются проверкой. GitHub добавляет SHA-256 каждого asset в API. Плагин скачивает только установщик из фиксированного репозитория, с точным именем и доступным SHA-256.

Заменять запущенную DLL или автоматически запускать установщик не нужно: пользователь получает файл после согласия, закрывает OBS и запускает установку отдельно.
