# MultiCamera T.E.

**До пяти смартфонов Android как отдельные камеры Windows и источники OBS.**

*Turn up to five Android phones into Windows cameras and OBS sources.*

**Русский** · **[English](README.en.md)**

Wi-Fi, USB, свой интернет-сервер, микрофон, стабилизация и поддерживаемые камерой 60 FPS.

## Скачать и установить

- **[Установщик Windows](https://github.com/Teninz/obs-lan-camera/releases/latest/download/MultiCameraTE-Setup.exe)** — Windows 11 x64.
- **[Приложение Android](https://github.com/Teninz/obs-lan-camera/releases/latest/download/OBS-LAN-Camera-Android.apk)** — Android 8 и новее.
- [Все файлы и изменения](https://github.com/Teninz/obs-lan-camera/releases/latest) · [SHA-256](https://github.com/Teninz/obs-lan-camera/releases/latest/download/SHA256SUMS.txt).

Запустите EXE и отметьте нужные карточки:

| Выбор | Для чего |
| --- | --- |
| **Приложение** | До пяти отдельных камер для совместимых программ звонков и OBS. |
| **Плагин OBS** | Прямое подключение смартфона к сцене OBS. |
| **Оба компонента** | Пять независимых камер через общий приёмник в OBS. |

Нажмите **«Установить выбранное»**. Для приложения нужен **WebView2 Runtime**, для плагина — **OBS Studio 33 x64**. Установите APK на телефон и разрешите камеру; микрофон — по желанию. **USB-отладка не нужна.**

## Подключить по Wi-Fi

1. Подключите ПК и телефон к одному роутеру. Ethernet на ПК + Wi-Fi на телефоне подходят.
2. На ПК: **MultiCamera T.E. → «Подключить»** у камеры → **Wi-Fi / LAN**.
3. На телефоне: **QR → правый QR подключения → круглая кнопка запуска**. Левый QR нужен для скачивания APK.
4. В программе звонков выберите **MultiCamera T.E. 1–5**. Для каждого телефона используйте отдельную карточку. Держите приёмник на ПК запущенным.

**В OBS:** добавьте источник **«MultiCamera T.E. — Смартфон»**, выберите номер камеры. Для каждой камеры — отдельный источник.

**Только плагин:** добавьте **«Камера смартфона по Wi-Fi»**, откройте окно подключения в свойствах источника и считайте его QR приложением телефона.

## USB и интернет

- **USB:** кабель с передачей данных → **USB-модем** в Android → **USB-кабель** на ПК → выберите адаптер телефона → **«Разрешить USB-подключение»** → считайте QR и запустите камеру.
- **Интернет:** нужен свой WSS-сервер с доверенным HTTPS-сертификатом. Укажите его в настройках ПК. [Инструкция сервера](relay/README.md).

## Полезно знать

- Начните с **720p / 30 FPS**. 60 FPS и стабилизация зависят от модели и режима. **«Стаб.» → приоритет стабилизации** выбирает режим до 1080p/30.
- **Выключенный экран:** луна → **«Работать с выключенным экраном»** → разрешите уведомления → выключите экран кнопкой питания. Управление — из уведомления. Скоростные 60 FPS в фоне пока заменяются на 30 FPS.
- Выход камер Windows — **720p**. Звук телефона передаётся в OBS; отдельного виртуального микрофона Windows пока нет. Несколько камер одновременно доступны, если это поддерживает принимающая программа.
- Если подключения нет: проверьте общий роутер, изоляцию гостевого Wi-Fi и локальные разрешения брандмауэра.
