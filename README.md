# OBS LAN Camera

Камера Android напрямую в OBS по домашней сети. На ПК работает нативный плагин OBS; на смартфоне — небольшое приложение. ПК можно подключить к роутеру кабелем, а смартфон — по Wi-Fi того же роутера.

**Версия 0.3.0 — экспериментальная.** Камера и переключаемый микрофон смартфона в OBS, полноэкранное превью с сохранением пропорций, режимы по возможностям камеры и окно с двумя QR внутри OBS. Протокол видео/звука проверен настоящим libobs; новые функции Android требуют проверки на вашем устройстве.

## Установка

1. Установите обычную 64-битную версию **OBS Studio 33** для Windows 10/11. Проверено с OBS 33.0.1 и его библиотеками `avcodec-62.dll` / `avutil-60.dll`.
2. Закройте OBS и запустите **OBS-LAN-Camera-Setup.exe**. Он обнаружит OBS или предложит выбрать папку, затем установит плагин. Если потребуются права записи, Windows запросит подтверждение администратора.
3. В OBS откройте **Источники → + → Камера смартфона по Wi-Fi**.
4. При первом появлении источника после запуска OBS автоматически открывается **окно подключения с двумя QR**. Его также можно открыть кнопкой **«Подключить смартфон / скачать Android-приложение»** в свойствах источника. Браузер для сопряжения не нужен.
5. Левый QR открывает APK на GitHub: считайте обычной камерой Android и установите приложение. Android может запросить разрешение на установку APK из браузера.
6. В приложении нажмите **QR**, считайте правый код и нажмите **круглую кнопку запуска**.
7. Кнопка **«Микр. выкл / вкл»** включает и выключает микрофон. По умолчанию он выключен; Android запрашивает разрешение только при первом включении. В OBS звук появляется у этого же источника смартфона в микшере.

Во время передачи оставьте приложение открытым. Экран удерживается включённым. При уходе из приложения камера останавливается. Начните с «Авто» (целевой режим 720p / 30 кадров/с). Список разрешений и частот строится по возможностям камеры и H.264-кодировщика: отображаются в том числе 4K/60, если устройство сообщает поддержку. Одновременная работа камеры и превью может потребовать более лёгкого режима; приложение показывает фактически запущенный режим. Если Surface-кодирование не запускается, предусмотрен резервный YUV-режим до 640×480 / 15 кадров/с. Превью можно заполнить с обрезанием краёв либо вписать целиком; оба варианта сохраняют пропорции. Переднюю и заднюю камеры можно переключать кнопкой справа. При разрыве соединения приложение повторяет подключение.

Установщик не меняет сцены OBS и брандмауэр. Windows Firewall должен разрешать входящее соединение для `obs64.exe` на выбранный TCP-порт, по умолчанию **34871**, только из вашей локальной сети. В гостевой Wi-Fi-сети может быть включена изоляция устройств — тогда подключение к ПК недоступно. Для использования вне домашней сети этот инструмент не предназначен.

Установщик пока не имеет коммерческой цифровой подписи Windows. Проверить SHA-256 файлов можно по `SHA256SUMS.txt` в релизе и контрольным суммам GitHub.

## Обновления

При запуске модуля OBS в фоновом потоке запрашивается последний обычный GitHub Release. Ошибка интернета не мешает камере работать. Также есть кнопка **«Проверить обновления плагина»** в свойствах источника.

Если найдена более новая версия с корректным установщиком, показывается окно с версией, размером и описанием изменений из релиза. До нажатия **«Да»** установщик не скачивается. Кнопка «Нет» выбрана по умолчанию.

После согласия установщик скачивается по HTTPS в **Загрузки / OBS LAN Camera**. Размер и SHA-256 проверяются по данным GitHub Releases. Установщик не запускается автоматически: закройте OBS и запустите его самостоятельно. Предыдущая папка плагина сохраняется в `%ProgramData%\obs-studio\plugin-backups`.

QR в плагине ссылается на APK той же версии, что и плагин: `/releases/download/v0.3.0/OBS-LAN-Camera-Android.apk`. Он не зависит от того, какой другой релиз GitHub пометил последним. Прямые ссылки в разделе скачивания по-прежнему ведут на последний релиз.

Android-приложение также проверяет GitHub при запуске. Если есть новая версия APK, показывает её номер и описание изменений и спрашивает, скачать ли обновление. После согласия проверяются размер, SHA-256, имя пакета, новая версия и совпадение подписи с установленным приложением. Затем открывается системный установщик Android; при необходимости он потребует отдельное разрешение на установку из этого приложения. Тихой установки нет. Ручная проверка находится в настройках приложения; там же указан номер установленной версии. Без интернета камера продолжает работать. Прежние APK без этой функции нужно один раз обновить вручную.

## Передача видео и приватность

- Android Camera2 → MediaCodec H.264 → TCP → FFmpeg в OBS; предпочтение аппаратному кодированию.
- Звук: PCM16 mono 48 кГц (резерв 44,1 кГц), пакеты около 20 мс по тому же зашифрованному каналу. При выключении микрофон освобождается.
- Сопряжение по случайному 128-битному ключу из QR. Ключ не передаётся в открытом виде.
- Пакеты видео и звука защищены AES-256-GCM; ключ сеанса зависит от двух новых случайных значений. Проверяются порядок сообщений и теги аутентификации.
- Видео передаётся непосредственно между смартфоном и ПК. Облачного ретранслятора и аккаунта приложения нет. Микрофон используется только после включения пользователем.
- GitHub используется для распространения APK и установщика и проверки версии. Ключ камеры, видео и звук туда не отправляются.
- Страница с ключом сопряжения доступна только через loopback на компьютере OBS. Страница скачивания APK может открываться из локальной сети.

## Ручная установка и удаление

Закройте OBS. Распакуйте ZIP так, чтобы DLL находилась по пути:

```text
C:\ProgramData\obs-studio\plugins\obs-lan-camera\bin\64bit\obs-lan-camera.dll
```

Рядом должна быть папка `data` с интерфейсом подключения, переводами и Android APK. Для удаления удалите источник из OBS, закройте OBS и удалите папку `obs-lan-camera`. Резервные копии и настройки OBS находятся отдельно.

## Разработка

Исходники плагина — `plugin/src`, Android-приложения — `android/src`, установщика — `installer`. Лицензия GPL-2.0-or-later; генераторы QR — MIT, ZXing — Apache-2.0. См. `COPYING`, заголовки файлов и `THIRD-PARTY-*`.

Нужны Python, Zig 0.14.1, исходники OBS 33.0.1 (`libobs` и `deps/w32-pthreads`), публичные заголовки FFmpeg 8, JDK 17, Android SDK Platform 35 / Build Tools 35.0.1 и ZXing Core 3.5.3. Сборка не требует Gradle. Пример:

```powershell
python build.py --work build-work --zig C:\tools\zig\zig.exe --obs-source C:\src\obs-studio --ffmpeg C:\src\ffmpeg-8.0 --sdk C:\Android\Sdk --jdk C:\Java\jdk-17 --zxing C:\libs\core-3.5.3.jar --installer
```

Для FFmpeg нужны сгенерированные заголовки `libavutil/avconfig.h` для Windows x64. Установленный OBS предоставляет библиотеки; их бинарники не копируются в комплект. Для другой папки OBS используйте `--obs-bin`.

При первой сборке APK в рабочей папке создаётся личный ключ подписи. **Храните его в резервной копии и не публикуйте**: обновления установленного APK должны подписываться тем же ключом. Для сборки оригинальных релизов используется один сохранённый ключ; он не входит в репозиторий и установщик.

Формат протокола и проверки описаны в `PROTOCOL.md` и `VERIFICATION.md`.
