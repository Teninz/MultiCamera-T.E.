# MultiCamera T.E.

До пяти смартфонов Android как отдельные камеры Windows и источники OBS. ПК может подключаться к роутеру кабелем, телефоны — по Wi-Fi. Есть режим USB-кабеля и подключение через собственный интернет-сервер.

**Экспериментальный выпуск 0.4.2.** Windows 11 x64; для плагина — OBS Studio 33 x64. В Windows доступны пять независимых устройств **MultiCamera T.E. 1–5**. Выбирайте нужное устройство в приложении для звонков; несколько камер одновременно доступны там, где это поддерживает само приложение. Системная регистрация и захват проверены через Windows Media Foundation. Проверка в каждой версии Zoom, Telegram и других программ отдельно не выполнялась.

## Первое подключение

1. Закройте OBS и MultiCamera T.E., запустите установщик. Windows запросит права администратора для регистрации камер и ограниченного правила локального доступа. Настройки и сцены OBS сохраняются; прежние файлы остаются в резервной папке.
2. Запустите MultiCamera T.E. обычным пользователем. Должна появиться надпись **«Камеры Windows готовы»**. Для работы камер держите приёмник запущенным.
3. У нужной карточки нажмите **«Подключить смартфон»**. В одном окне находятся QR скачивания APK и индивидуальный QR подключения.
4. Установите APK, затем в Android-приложении нажмите **QR**, считайте правый код и нажмите круглую кнопку запуска.
5. В Zoom, Telegram или другом совместимом приложении выберите **MultiCamera T.E. 1**, **2** и т. д. Для каждого следующего смартфона используйте отдельную карточку. Один слот принимает одно устройство; повторное подключение с тем же ключом не вытесняет действующую камеру.

Приёмник выдаёт стабильный формат **1280 × 720 NV12**, 30 или 60 кадров/с по запросу программы-потребителя. Входное изображение телефона масштабируется с сохранением пропорций; вертикальное видео вписывается с полями. Выбор высокого разрешения на телефоне не увеличивает выход Windows выше 720p в этом выпуске. Начинайте с 720p / 30 кадров/с, особенно при работе нескольких устройств.

## Три способа подключения

**Локальная сеть.** Выберите этот режим в окне подключения. ПК и телефон должны находиться в сети одного роутера. Кабель Ethernet на ПК и Wi-Fi на телефоне подходят. Изоляция клиентов гостевой Wi-Fi-сети может мешать подключению. Приёмник использует TCP **34872**; установщик ограничивает доступ исполняемым файлом, выбранным локальным адресом и подсетью.

**USB-кабель.** Подключите телефон кабелем с передачей данных и включите **«USB-модем»** в настройках Android. На ПК выберите режим **USB-кабель**, нужный USB-адаптер и нажмите **«Разрешить USB-подключение»**. Помощник покажет конкретный адаптер и подсеть, затем запросит повышение прав. Создаётся отдельное правило только для этого USB-интерфейса, адреса и TCP 34872. Считайте правый QR приложением на телефоне и запустите передачу. Видеопоток идёт по кабелю. При смене USB-адреса повторите разрешение. Наличие USB-модема зависит от прошивки Android.

**Интернет / свой сервер.** В настройках Windows укажите `wss://ваш-сервер` и его ключ доступа, включите интернет-подключения. Для сопряжения выберите интернет-режим и считайте QR нужной карточки. Устройства устанавливают исходящие соединения с вашим сервером. [Комплект и инструкция своего сервера](relay/README.md). Размещение общего сервера в приложение не входит. Сертификат HTTPS должен быть доверенным.

## OBS: пять отдельных камер

Добавляйте **Источники → + → MultiCamera T.E. — камера смартфона** и выбирайте номер устройства в свойствах. Создавайте новый источник для каждого смартфона. Источники независимо перемещаются, масштабируются, обрезаются, скрываются и получают обычные фильтры OBS; их звук также разделён. Кнопка в свойствах открывает общий приёмник.

Старый источник **«Камера смартфона по Wi-Fi»** сохранён для прямого подключения одного телефона к OBS на TCP **34871**. Его существующие настройки и QR остаются совместимыми. Новый режим нескольких устройств использует общий приёмник и источники MultiCamera T.E.

## Android: камера, микрофон и затемнение

- Превью можно заполнить с обрезанием краёв или вписать целиком. Оба режима сохраняют пропорции при повороте телефона.
- Разрешения и FPS определяются по возможностям выбранной камеры, превью и H.264-кодировщика. Кнопка FPS предлагает 60 кадров/с, если такой режим доступен. Высокое разрешение и частота не гарантируют производительность при перегретом телефоне или перегруженном соединении.
- Автоматически запрашивается поддерживаемая EIS / preview EIS / OIS. Индикатор учитывает фактический ответ камеры; при 60 FPS или высоком разрешении возможны ограничения. Исправление превью и доступность стабилизации/60 FPS подтверждены пользователем в версии 0.3.1.
- **Микрофон вкл/выкл**: по умолчанию выключен. При включении Android запрашивает разрешение; при выключении захват освобождается. Звук передаётся в соответствующий источник OBS. Отдельных виртуальных микрофонов Windows в этом выпуске нет.
- Кнопка **☾** затемняет экран во время передачи, сохраняя работу камеры и микрофона. Вернуть экран можно двойным касанием, свайпом от любого угла или кнопкой громкости. В настройках доступно автоматическое затемнение после 30 секунд без касаний. Яркость меняется только для окна приложения и восстанавливается при выходе из режима.
- Оставляйте приложение открытым. Затемнение является режимом приложения; уход в другое приложение или блокировка Android останавливает камеру.

Интерфейс Windows и Android, подписи OBS и сообщения установщика доступны на русском, английском, японском, испанском и упрощённом китайском. Язык выбирается в приложениях; первоначально используется язык системы. В Windows есть сглаженное стеклянное оформление и отключаемая анимация подсветки; при сворачивании её отрисовка останавливается.

## Обновления и данные

Плагин OBS проверяет GitHub при запуске; при новой версии показывает номер и описание и спрашивает, скачать ли установщик. До согласия EXE не скачивается; после скачивания проверяются размер и SHA-256. Установщик запускает пользователь после закрытия OBS и приёмника.

Android-приложение проверяет обновления при запуске и через настройки. Перед скачиванием запрашивается согласие. Проверяются размер, SHA-256, имя пакета, версия и совпадение подписи; установку подтверждает пользователь в системном окне Android. QR скачивания привязан к версии установленного компонента, а не к произвольному последнему релизу.

Камеры соединяются по индивидуальным случайным ключам. OLC1 защищает пакеты видео и звука AES-256-GCM с новыми значениями сеанса и проверкой порядка сообщений. Интернет-транспорт дополнительно использует WSS. Настройки и ключи Windows защищены DPAPI текущего пользователя; локальные каналы доступны ему, SYSTEM и LocalService, но не удалённым клиентам. GitHub используется для распространения и проверки обновлений; видео, звук и ключи камер туда не отправляются.

APK подписывается постоянным ключом проекта. Установщик Windows пока не имеет коммерческой Authenticode-подписи. Контрольные суммы опубликованы в релизе.

## Ручная установка и удаление

ZIP плагина предназначен для размещения в `%ProgramData%\obs-studio\plugins\obs-lan-camera`: рядом с `bin/64bit/obs-lan-camera.dll` нужна папка `data`. Для пяти Windows-камер и USB-помощника рекомендуется EXE-установщик.

Камеры Windows существуют, пока запущен приёмник, и исчезают после его закрытия. Полный автоматический деинсталлятор пока не предусмотрен. Для ручного удаления закройте OBS и приёмник, удалите установленный плагин и папку `%ProgramFiles%\MultiCamera T.E`; отдельно можно удалить правила `MultiCameraTE-LAN-34872` / `MultiCameraTE-USB-*`, ярлык меню Пуск и настройки `%LocalAppData%\MultiCameraTE`. Регистрация пяти COM-классов перечислена в `hub/src/vcam.h`; она относится только к этому компоненту. Сцены OBS и резервные копии находятся отдельно.

## Разработка

Исходники: `hub/src` — приёмник Windows и виртуальные камеры; `android/src` — Android; `plugin/src` — OBS; `relay` — свой сервер. Лицензия GPL-2.0-or-later; см. `COPYING` и `THIRD-PARTY-*`.

Нужны Python, Zig 0.14.1, JDK 17, Android SDK Platform 35 / Build Tools 35.0.1 и ZXing Core 3.5.3. Для плагина дополнительно нужны исходники OBS 33.0.1 и заголовки FFmpeg 8; установленные библиотеки OBS не копируются в дистрибутив. Общий приёмник использует системный Windows Media Foundation и работает без установленного OBS. ## Стабилизация,60FPS и выключение экрана

В Android нажмите «Стаб.»: доступны авто, приоритет стабилизации (до1080p/30FPS) и выключение. НаRealmeGTMasterEdition EIS подтверждена для передаваемого видео, но previewEIS не поддерживается. Штатная камера производителя может иметь дополнительные закрытые алгоритмы.

Для60FPS приложение использует обычные режимы либо совместимую скоростную сессию120FPS с ограничением входа кодировщика60FPS. НаRealme720p измерено около60FPS; такой путь расходует больше энергии. Разрешения и частоты зависят от модели.

Луна → «Работать с выключенным экраном» запускает фоновую службу. Разрешите уведомления, затем выключите экран кнопкой питания. В уведомлении есть остановка и возврат в приложение. При возврате фоновая передача останавливается; нажмите запуск для предпросмотра. Скоростной режим60FPS в фоне пока заменяется30FPS. Прежнее затемнение остаётся отдельным вариантом. USB-отладка не нужна.
