# Обновления, данные и удаление

Плагин OBS проверяет GitHub при запуске; при новой версии показывает номер и описание и спрашивает, скачать ли установщик. До согласия EXE не скачивается; после скачивания проверяются размер и SHA-256. Установщик запускает пользователь после закрытия OBS и приёмника.

Android-приложение проверяет обновления при запуске и через настройки. Перед скачиванием запрашивается согласие. Проверяются размер, SHA-256, имя пакета, версия и совпадение подписи; установку подтверждает пользователь в системном окне Android. QR скачивания привязан к версии установленного компонента, а не к произвольному последнему релизу.

Камеры соединяются по индивидуальным случайным ключам. OLC1 защищает пакеты видео и звука AES-256-GCM с новыми значениями сеанса и проверкой порядка сообщений. Интернет-транспорт дополнительно использует WSS. Настройки и ключи Windows защищены DPAPI текущего пользователя; локальные каналы доступны ему, SYSTEM и LocalService, но не удалённым клиентам. GitHub используется для распространения и проверки обновлений; видео, звук и ключи камер туда не отправляются.

APK подписывается постоянным ключом проекта. Установщик Windows пока не имеет коммерческой Authenticode-подписи. Контрольные суммы опубликованы в релизе.

## Ручная установка и удаление

ZIP плагина предназначен для размещения в `%ProgramData%\obs-studio\plugins\obs-lan-camera`: рядом с `bin/64bit/obs-lan-camera.dll` нужна папка `data`. Для пяти Windows-камер и USB-помощника рекомендуется EXE-установщик.

Камеры Windows существуют, пока запущен приёмник, и исчезают после его закрытия. Полный автоматический деинсталлятор пока не предусмотрен. Для ручного удаления закройте OBS и приёмник, удалите установленный плагин и папку `%ProgramFiles%\MultiCamera T.E`; отдельно можно удалить правила `MultiCameraTE-LAN-34872` / `MultiCameraTE-USB-*` / `MultiCameraTE-OBS-34871`, ярлык меню Пуск и настройки `%LocalAppData%\MultiCameraTE`. Регистрация пяти COM-классов перечислена в `hub/src/vcam.h`; она относится только к этому компоненту. Сцены OBS и резервные копии находятся отдельно.
